# Banco de Dados

Esta pasta reúne projetos de banco de dados e integração com aplicações. Aqui estão scripts SQL e um sistema em Java que conecta o código a um banco MySQL.

## Objetivo

Organizar o estudo de conceitos de banco de dados e integração com aplicações, incluindo:

- modelagem de tabelas e scripts SQL
- criação de banco de dados e scripts de carga
- integração Java com MySQL através de JDBC
- gerenciamento de pedidos e vendas em sistema ligado ao banco

## O que tem dentro

- `Banco-de-Dados` - repositório com scripts e arquivos relacionados a estudos de banco de dados.
- `Sistema-de-Gestao-de-Pedidos-e-Integracao-Relacional` - sistema de vendas em Java integrado com MySQL. Permite cadastrar clientes, produtos, criar pedidos e gerar relatórios.

## Para que serve

Esta pasta serve para centralizar trabalhos de banco de dados e projetos que demonstram a conexão entre lógica de aplicação e persistência de dados. É ideal para estudar SQL, modelagem relacional e o desenvolvimento de aplicações que usam banco de dados reais.
