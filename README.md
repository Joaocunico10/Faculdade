# Perfil GitHub de João Cunico

Este repositório local organiza meus projetos do GitHub em categorias claras para facilitar o estudo e a navegação. Você também pode ver meus projetos principais no meu perfil pessoal: https://github.com/Joao-Paulo-Cunico.

## Sobre o perfil

Aqui estão meus trabalhos de estudo em diferentes áreas de desenvolvimento:

- front-end web com HTML, CSS, JavaScript e Vue.js
- banco de dados e integração de aplicações com MySQL
- programação orientada a objetos em Java
- scripts e exercícios em PHP

## Como está organizado

- `Front-End/` — projetos e práticas de front-end, incluindo páginas web, layouts, animações, formulários, projetos de aulas e um aplicativo Vue.js com roteamento.
- `Banco-de-Dados/` — estudos de banco de dados e integração com aplicações, incluindo scripts SQL e um sistema de pedidos em Java com conexão MySQL.
- `POO/` — trabalhos em Java que usam os princípios de POO, como classes, interfaces, abstração e encapsulamento.
- `PHP/` — exercícios e trabalhos em PHP voltados para desenvolvimento de páginas dinâmicas e formulários.

## Para que serve

Este repositório serve como uma visão organizada do meu aprendizado e das minhas experiências. Ele ajuda a separar meus estudos por área, permitindo revisar mais facilmente:

- habilidades de front-end e construção de interfaces
- conhecimentos de banco de dados relacionais e backend simples
- fundamentos de orientação a objetos em Java
- uso de PHP para páginas dinâmicas e processamento de dados

## Observação

Cada pasta contém os repositórios originais do perfil, preservando a estrutura dos projetos para estudo ou continuação.
