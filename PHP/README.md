# PHP

Esta pasta contém projetos e exercícios de PHP do meu perfil.

## Objetivo

Organizar práticas de programação com PHP, especialmente scripts de servidor e formulários web.

## O que tem dentro

- `PHP` - repositório com exercícios de PHP e exemplos de formulários. Inclui arquivos `.php` que demonstram lógica de servidor, processamento de dados e integração básica com HTML.

## Para que serve

Esta pasta serve como registro do estudo de PHP e de desenvolvimento back-end simples. Os projetos ajudam a aprender como criar páginas dinâmicas, processar entradas de usuários e gerar conteúdo usando PHP no servidor.
