# Front-End

Esta pasta contém projetos de front-end do perfil GitHub de João Cunico. Aqui estão exercícios e trabalhos com HTML, CSS e JavaScript, além de projetos em Vue.js e exemplos de roteamento.

## Objetivo

Organizar os estudos e práticas de desenvolvimento de interfaces web, incluindo:

- layouts com CSS puro
- posicionamento e flexbox
- grid layout
- manipulação de DOM com JavaScript
- projetos de aula e trabalhos práticos
- aplicações Vue.js com roteamento

## O que tem dentro

- `Api-Roteamento-JS` - projeto em Vue.js que usa roteamento e estrutura de SPA.
- `Atividade-Js` - atividades de JavaScript com páginas HTML e scripts.
- `Atividade-posicionamento` - exercícios de posicionamento CSS e layout.
- `Aula` - exemplos e exercícios de aula de front-end.
- `Aula2` - material de aula com páginas HTML.
- `aulajs` - projetos de JavaScript e Node/Vue de curso.
- `Aula_professor_frontend` - exercícios de aula do professor voltados para front-end.
- `Front-End` - repositório com conteúdo de front-end de estudos anteriores.
- `Projeto-Pr-tico-de-Desenvolvimento-Front-End` - projeto prático com interface web e imagens.
- `Trabalho` - trabalho de front-end com páginas web.
- `Trabalho-aulo08-Front-end` - atividade do módulo de front-end da aula 08.
- `Trabalho-flexbox` - prática de layout usando flexbox.
- `Trabalho-frontend` - trabalho geral de front-end com HTML e CSS.
- `Trabalho-Grid` - projeto de layout usando CSS Grid.
- `Turma-A---Site-` - site de turma com páginas HTML.

## Para que serve

Esta pasta serve como referência de aprendizado e portfólio de pequenos projetos web. Ela mostra a evolução dos estudos de front-end de João, com foco em design responsivo, posicionamento de elementos, interatividade com JavaScript e uso de ferramentas modernas como Vue.js.
