Alinhamento e Centralização

Existem diversas formas de alinhar elementos horizontal e verticalmente no CSS. As principais abordagens variam conforme o contexto e o tipo de elemento.

Vamos ver as formas mais comuns:

  • margin: auto;
  • text-align (para textos e inline-blocks)
  • position + transform
  • display: flex;
  • display: grid;

1. Centralização Horizontal com margin: auto;

Funciona para elementos block com largura definida.

Centro

.box {
  width: 100px;
  margin: 0 auto;
}

2. Centralização com position e transform

Combina position: absolute; com transform: translate para centralizar o elemento em qualquer direção.

Centro

.box {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}

3. Centralização com Flexbox

O Flexbox é uma das formas mais modernas e simples de centralizar elementos, tanto horizontal quanto verticalmente.

Centro

.container {
  display: flex;
  justify-content: center;
  align-items: center;
}

4. Centralização com Grid

Com o CSS Grid, é possível centralizar facilmente com apenas uma linha.

Centro

.container {
  display: grid;
  place-items: center;
}

Atividade Prática

Crie uma página que contenha:

  • Um quadrado centralizado com margin: auto;;
  • Um elemento centralizado com position e transform;
  • Um contêiner com display: flex; e centralização dupla;
  • Outro com display: grid; e place-items: center;.

Compare o comportamento de cada método e descubra qual é o mais prático para cada situação.
