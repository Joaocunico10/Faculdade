Introdução

O que é o Flexbox e por que ele é útil no CSS?

O Flexible Box Module, mais conhecido como Flexbox, foi projetado para facilitar o posicionamento e o alinhamento dos elementos em um layout. Ele funciona como um modelo de layout unidimensional, organizando os itens de forma eficiente em uma única linha ou coluna, e oferecendo um controle preciso sobre o espaçamento, alinhamento e distribuição dos elementos na página.

Formas mais comuns:

  • display: flex
  • flex-direction
  • justify-content
  • align-items

Formas intermediárias

O Flexbox intermediário amplia as funcionalidades básicas do Flexbox, permitindo um controle mais sofisticado do layout. Com flex-wrap, os itens podem quebrar para a próxima linha quando não cabem em uma única, tornando o layout mais responsivo. A propriedade align-content organiza a distribuição das linhas dentro do container, garantindo um alinhamento uniforme quando há múltiplas linhas. Com order, é possível reorganizar a ordem visual dos itens sem alterar o HTML, oferecendo flexibilidade no design. Já o flex-grow permite que os itens cresçam proporcionalmente para ocupar o espaço disponível, criando layouts fluídos e equilibrados.

Formas de usar:

  • flex-wrap
  • align-content
  • order
  • flex-grow

3. Centralização com Flexbox

O Flexbox é uma das formas mais modernas e simples de centralizar elementos, tanto horizontal quanto verticalmente.

Centro

Resumo - Flexbox basico e intermediário

Flexbox básico:

Organiza itens em linha ou coluna (flex-direction).
Controla alinhamento principal e cruzado (justify-content e align-items).
Útil para layout simples e centragem de elementos.

Flexbox intermediário

Permite itens quebrarem linha (flex-wrap).
Controla distribuição de múltiplas linhas (align-content).
Possibilita reorganizar itens sem alterar HTML (order).
Ajusta crescimento proporcional dos itens (flex-grow).
