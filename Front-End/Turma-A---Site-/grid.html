Divisão de elementos em linhas e colunas

O CSS Grid é uma técnica de layout que organiza elementos em um sistema de linhas e colunas, parecido com uma tabela, mas muito mais flexível e moderno. Ele permite que você posicione itens tanto horizontal quanto verticalmente de forma precisa.

Comandos para usa-lo

  • display: grid;
  • place-itens: center;

Centralização com Grid

Com o CSS Grid, é possível centralizar facilmente com apenas uma linha.
