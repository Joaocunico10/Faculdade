# POO

Esta pasta reúne projetos de Programação Orientada a Objetos (POO) em Java do perfil.

## Objetivo

Centralizar exercícios e trabalhos de Java que usam conceitos de orientação a objetos, como classes, objetos, métodos, encapsulamento, herança, interfaces e abstração.

## O que tem dentro

- `Aula07` - atividades de aula com exercícios em Java.
- `Moacir---Atividade09` - atividade em Java.
- `POO` - coleção maior de exercícios de Java, incluindo listas, interfaces, abstração e trabalhos de encapsulamento.

## Para que serve

Esta pasta serve para documentar e armazenar o aprendizado de Java orientado a objetos. Os projetos são úteis para estudar como estruturar código em classes, organizar lógica de negócio e trabalhar com conceitos fundamentais de POO.
